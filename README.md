# HumanBenchmark Automation Experiments

This repository contains a collection of small Python scripts
developed as automation and experimentation exercises.

Each script targets a different HumanBenchmark test and was created
to explore topics such as:
- input simulation
- reaction timing
- pattern recognition
- basic automation logic

These scripts were written purely for educational and experimental purposes.
They are not intended for competitive use or misuse on public platforms.

The project exists as a personal archive of automation experiments.
